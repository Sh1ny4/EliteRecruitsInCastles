A Bannerlord mod that moves the elite recruits from castle bound villages to the castles

https://www.nexusmods.com/mountandblade2bannerlord/mods/5734


### Optional trees : 
It is possible with this mod to have troop trees specific to each settlement type : 
- the basic recruits spawns in villages
- the elite recruits spawns in castles
- optional : a troop tree with its recruit id being ``<culture ID>_town_recruit`` will spawn in towns
- optional : a troop tree with its recruit id being ``<culture ID>_marine_recruit`` will spawn in towns with a port or fishing villages
